รูปแบบแต่ละ test case ต้องมี:
- TC-ID
- Module
- Scenario
- Preconditions
- Test Data
- Steps
- Expected Result
- Actual Result
- Status
- Severity

ข้อกำหนด:
- ครอบคลุม workflow T-01 ถึง T-14
- ครอบคลุม Public, Citizen, Staff, Agency, Executive
- ครอบคลุม Anonymous complaint และการเปิดเผยตัวตนโดย super_admin
- ครอบคลุม Dashboard, Report, Export Excel
- ครอบคลุม Notification, SLA, Escalation
- ครอบคลุม Security/Permission
- แยก Severity เป็น Blocker, Major, Minor
- Actual Result และ Status ให้เว้นว่างไว้สำหรับผู้ทดสอบกรอก
- ใช้ภาษาไทย
- ไม่ต้องแก้โค้ด
- หลังสร้างไฟล์ ให้สรุปจำนวน test cases แยกตาม module
